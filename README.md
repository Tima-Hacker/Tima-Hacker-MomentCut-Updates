## ⚙️ Система обновлений

Проект предусматривает автоматическую проверку обновлений при запуске MomentCut.

**Планируемая схема работы:**

1. 🔍 Программа проверяет наличие новой версии.
2. 📥 При обнаружении обновления скачивает установщик.
3. 🛡️ Проверяет целостность загруженного файла.
4. 🚀 Запускает установку обновления.

*Автоматическое обновление станет доступно после завершения интеграции и тестирования.*

## 📦 Публикация новых версий

1. Соберите и подпишите установщики в исходном проекте MomentCut.
2. Создайте черновик релиза с тегом `vMAJOR.MINOR.PATCH`.
3. Добавьте установщики, метаданные обновления и описание изменений.
4. Перейдите в **Actions → Publish MomentCut release → Run workflow**.
5. Укажите тег черновика и запустите публикацию.

Workflow проверяет формат тега и наличие файлов перед выпуском релиза.

## 🔐 Безопасность

- Не публикуйте пароли, токены и ключи цифровой подписи.
- Не размещайте закрытый исходный код.
- Проверяйте цифровые подписи установщиков на стороне приложения.
