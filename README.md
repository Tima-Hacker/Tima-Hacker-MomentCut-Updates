# MomentCut Updates

Публичный канал распространения обновлений MomentCut. Исходный код приложения здесь не хранится.

- [Релизы](https://github.com/Tima-Hacker/Tima-Hacker-MomentCut-Updates/releases)
- [API последней стабильной версии](https://api.github.com/repos/Tima-Hacker/Tima-Hacker-MomentCut-Updates/releases/latest)

## Публикация

1. Соберите и подпишите установщики в исходном проекте MomentCut.
2. Создайте черновик релиза с тегом `vMAJOR.MINOR.PATCH`, добавьте установщики, необходимые метаданные обновления и описание изменений.
3. Откройте Actions → Publish MomentCut release → Run workflow и укажите тег черновика. Workflow проверяет тег и наличие загруженных файлов перед публикацией.

Не публикуйте токены, ключи подписи или исходный код. Проверка файлов в workflow не заменяет проверку цифровой подписи на стороне приложения.

## Статус

Интеграция клиентского автообновления и автоматической сборки ожидает исходного проекта MomentCut. Тестовый релиз не опубликован.
